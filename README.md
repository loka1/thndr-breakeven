# أبيع على كام؟

حاسبة ويب بتقولك **أقل سعر بيع** يغطي عمولة ثاندر ورسوم البورصة المصرية (EGX) في الشراء والبيع، وبتعرض السعر على وزن القرش أو العشرة قروش أو الجنيه أو أي وزن تحدده.

**التجربة:** https://loka1.github.io/thndr-breakeven/

> A small Arabic (RTL) web calculator for Egyptian Exchange (EGX) investors on Thndr. Enter your shares and buy price and it gives you the lowest sell price that covers all brokerage and exchange fees, rounded to the tick size you choose.

## المميزات

- أقل سعر بيع يغطي كل الرسوم، مقرّب على وزن السعر (قرش، عشرة قروش، جنيه، أو وزن مخصص، أو حسب مستوى السعر في البورصة).
- الربح قبل الرسوم وبعد الرسوم في كل سعر.
- **هدف الربح** و**وقف الخسارة**: السعر اللي يحقق ربح أو خسارة محددة بعد الرسوم.
- **دفعات شراء متعددة** بأسعار مختلفة مع متوسط التكلفة الحقيقي.
- **باقات ثاندر**: العادية، العادية بحد أدنى، وثاندر تريدر مع عدّاد الـ 50 أمر المجانية.
- **الحد اليومي للسعر** وتنبيه لو السعر المطلوب برّاه.
- **سجل الصفقات** (مفتوحة ومقفولة) مع ملخص وتصدير CSV.
- **استيراد فاتورة ثاندر PDF** بيتقرا على جهازك بس.
- **مقارنة الباقات** حسب عدد أوامرك الشهرية.
- رابط مشاركة، أرقام عربية أو لاتينية، وضع داكن، وبيشتغل كتطبيق (PWA) بدون نت.

## إزاي الحساب بيتم

الرسوم بتتحسب على كل أمر شراء وبيع من نسب موجودة في أعلى ملف السكريبت (`DEFAULT_RATES`) ومصدرها [صفحة رسوم ثاندر](https://support.thndr.app/en/articles/638558-thndr-order-fees):

| البند | القيمة |
|---|---|
| عمولة ثاندر | 2 جنيه + 0.1% من قيمة الأمر (أو 0.1% بحد أدنى 2 جنيه بعد الأوامر المجانية في تريدر) |
| البورصة | 0.01% (حد أقصى 5,000) |
| مصر للمقاصة | 0.01% (حد أقصى 5,000) |
| الرقابة المالية | 0.005% بحد أدنى 1 جنيه على كل تنفيذ (حد أقصى 250) |
| حماية المستثمر | 0.005% |
| الدمغة | 0.05% (0.025% للبيع في نفس اليوم) |

سعر التعادل بيتحسب بالبحث العددي (bisection) عن أقل سعر `P` بحيث `P × الكمية − رسوم البيع ≥ تكلفة الشراء + الرسوم`، وبعدين بيتقرّب لأعلى على وزن السعر مع التأكد إن الشرط لسه متحقق.

> **تنبيه:** الأرقام تقديرية وليست نصيحة استثمارية. المشروع غير تابع لشركة ثاندر، وفاتورة ثاندر هي المرجع. وزن السعر والحد اليومي قيم افتراضية قابلة للتعديل ولازم تتراجع مع قواعد البورصة.

## التشغيل محلياً

مفيش build ولا dependencies. الصفحة ملف واحد:

```bash
git clone https://github.com/loka1/thndr-breakeven.git
cd thndr-breakeven
python3 -m http.server 8000   # أو افتح index.html مباشرة
```

افتح http://localhost:8000. (الـ service worker بيشتغل على `http://localhost` أو HTTPS بس.)
